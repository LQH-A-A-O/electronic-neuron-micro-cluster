# 接入指南 —— 把这套记忆层用在你自己的场景里

## 它是什么

把"记住的东西"分成三层信任等级，用一道**验证门控**决定什么知识有资格被长期复述：

    observe(key, value)    -> hot   照单全收，允许脏
    consolidate(validator) -> warm  只有通过验证的能进，然后被用于回放/检索
    load_cold(entries)     -> cold  只读锚点，只能由你显式写入

**它不是模型，是模型外面的一层记忆管理。** 它不产生能力，只把"你已有的验证能力"
转换成"抗污染的记忆"。

## 最快的接入方式

    import sys; sys.path.insert(0, "<本项目路径>")
    from mm import TieredMemory, NeighborValidator

    # 1) 准备验证池：一批你已知正确标签的历史样本（key 用和下面同样的表示）
    v = NeighborValidator(pool_x, pool_y, sim_floor=0.5, min_support=3)

    mem = TieredMemory(validator=v, theta=0.7,
                       capacity_hot=1024, capacity_warm=600,
                       retention="reservoir")

    # 2) 在线跑：看到什么先丢进热备
    mem.observe(key_vector, label_or_action)

    # 3) 每个周期巩固一次（比如每个任务/每天结束时）
    rep = mem.consolidate()
    print(rep.n_accepted, rep.n_rejected, rep.accept_rate)

    # 4) 回放/检索时只用 warm（经验证的）
    for e in mem.replay_pool():   # 默认返回 warm + cold
        train_on(e.key, e.value)

## 三个必须自己回答的问题

### Q1 我能拿到什么验证信号？（这是唯一的成本）

| 信号 | 怎么接 | 适合 |
|---|---|---|
| **环境奖励**（可执行/可测量） | 自己写 `Validator` 子类，score 里跑一次校验 | 代码、数学、可自动评测的任务 —— **最可靠** |
| **延迟标签** | `DelayedLabelValidator(NeighborValidator(...), lag=k)` | 反馈会到但会迟到（推荐、风控、广告） |
| **人工留出集** | `NeighborValidator` | 有标注预算 |
| **自洽投票** | `ConsensusValidator` | **危险**：只保证连贯，不保证正确；第一批知识错了会被一路放大 |

### Q2 我的验证器够准吗？

**先量，别猜。** 阶段 2 的结论是一条硬判据：

> 验证器把"对"判成"错"、把"错"判成"对"的**总错误率低于 50%**，这套门控就不会亏；
> 超过 50%，它比干脆不做门控**更差**（极端情况下比完全没有记忆还差）。

量法：拿一批已知真值的历史数据跑一遍 `consolidate(truth_fn=...)`，
读 `GateReport.false_accept_rate`（漏放率）和 `false_reject_rate`（误拒率）。

- 漏放率 > 50% → **别用**
- 漏放率 < 20% → 值得用

### Q3 我该选多大的 θ、要不要冷备？

- **θ**：越高越保守（漏放少、误拒多）。数据有冗余时宁可高（误拒只是浪费，漏放是污染）。
- **冷备**：温备装得下就不要冷备 —— 阶段 3 实测"连给它当前世界的真实原型都换不来正收益"。
  只有"温备装不下 + 类别多"时才加，而且**必须让它跟着世界更新（EMA）**：
  冻结的冷备在所有容量、所有比例下都劣于"干脆不要冷备"。

## 已知的坑

1. **key 的表示决定了门控的死活。** 余弦阈值在高维会"度量崩塌"：
   本项目真实数据上误拒了 41% 的干净条目。**先用欧氏距离或先白化**，再看误拒率。
2. **不要动 `truth_fn`。** 它只用于事后算污染率，门控自己看不到真值。
   顺手把真值塞进打分路径，实验就白做了（生产里也等于开卷考试）。
3. **温备的淘汰策略是个真变量。** 本项目第一版写成"保留最新"，直接导致门控看起来没用。
   默认的 `retention="reservoir"`（对全历史均匀）通常是对的。
4. **别拿热备做决策。** 热备就是"还没验证的东西"，它的用途只有一个：等着被巩固。
