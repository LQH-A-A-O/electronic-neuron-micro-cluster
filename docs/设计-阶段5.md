# 阶段 5 设计 —— 从"实验室结论"到"能用的东西"

## 一、四个阶段已经确立的东西

| 已确立 | 证据 |
|---|---|
| 有污染时，验证门控显著强于无门控回放 | 合成 +58% 相对；真数据 MNIST +43% 相对 |
| 增益随污染率上升；噪声为 0 时门控不花钱 | 阶段 1、阶段 4 |
| **验证器质量 = 这套架构的全部价值** | 用原演示那套验证器，三层结构退化成无门控回放 |
| 验证器的合格线：**错误率 < 50%**；超过就比不做更差 | 阶段 2，先推 q*=1/2 再实测（且与污染率无关） |
| 门控不产生能力，只是把 oracle 的能力转成抗污染能力 | 预算为 0 时精确退化成无记忆 |
| 「冷备永不更新」有害；冷备只在温备装不下时才值钱 | 阶段 3 |

## 二、阻碍落地的四个缺口（按严重程度排序）

1. **威胁模型是假的**。四个阶段用的都是"均匀随机翻转标签"。
   真实模型不会把 0 认成 7，它会在 4/9、3/5、7/1 之间犯迷糊 —— 错误是**结构化**的，
   落在类边界上。**门控在结构化错误下是否还成立，完全未知。**
2. **oracle 是免费的假设**。四阶段都假定"每个任务都有一份干净带标注的留出集"。
   现实里没有。真数据那一阶段还额外证明了这个假设有多贵（20 条/任务不如不做）。
3. **只实现了一条使用路径**（冷备参与回放）。构想里"用于对比校正"那条（读优先级、冲突仲裁）没做。
4. **误拒率 41%**（真数据、cosine 阈值 0.5）。有冗余数据兜着没翻车，但在小样本场景会变成真损失。

## 三、阶段 5 的三块

### 5A 结构化幻觉 —— 换掉假的威胁模型（本轮已跑，**预测被证伪**）
把噪声从"均匀翻转"换成**真实弱模型的混淆方向**：
- 先训一个弱 MLP，读出它的 10x10 混淆矩阵 —— 那就是真实错误的分布
- 用这个混淆矩阵生成脏标签，**错误率仍固定 40%**，与均匀噪声严格可比
- 门槛指标不是只有 ACC，还有**门控自己的混淆矩阵**：漏放率（脏的进了温备）、误拒率（干净的没进去）

可证伪预测：结构化错误更难挡，因为脏样本的 key 落在真实类簇的**边界**上，邻居投票会摇摆。

**实测结果：预测错了。** 漏放率两者都是 0.003，ACC 0.724 vs 0.719。
门控对"错误是随机还是混淆"完全不敏感 —— 它只看 key 和 value 匹不匹配。
真正的威胁只有两种：**key 本身错了**，或**错误恰好自洽**。详见 `报告-阶段5.md`。

### 5B 免费 oracle —— 现实里没人给你标 holdout（本轮已跑）
三种"不要钱"的验证信号：
| 信号 | 代价 | 适用 |
|---|---|---|
| 延迟标签 `DelayedLabelValidator(lag=k)` | 等 k 个任务 | 反馈会到、但会迟到（推荐系统/风控） |
| 自洽投票 `ConsensusValidator` | 零标注 | **实测失败**：污染率 0.404 ≈ 输入，ACC 0.240 < 不做门控的 0.481 |
| 环境奖励 | 需要可机械校验 | **实测唯一能直接用的**（与 gold 等价） |

**实测结论（阶段 5B）**：延迟标签在 class-incremental 下**完全失效**（0.125 = 无记忆），
根因是验证池只覆盖旧类、新类永远验不了 —— 它需要的是**事后回滚**机制，不是"更宽容的验证器"。

## 四、给要用的人的判据表（这是四个阶段最实用的产出）

**第 0 步：先量你的验证器。** 拿一批你已知真值的历史数据，跑一遍门控，读漏放率/误拒率。
- 漏放率 > 50% → **别用这套东西**，你会比不做门控更差（阶段 2 的 q*=0.5 判据）
- 漏放率 < 20% → 值得用

**第 1 步：选验证信号。** 优先级：环境奖励 > 延迟标签 > 人工留出集 > 自洽投票（最后这个只保连贯不保正确）。

**第 2 步：估容量。**
- 温备够大（能覆盖你所有需要记住的东西）→ **不要冷备**，它是冗余的，冻结的冷备还会主动误导
- 温备装不下 + 类别多 → 加冷备原型，但**必须让它跟着世界更新**（EMA）

**第 3 步：定阈值 θ。** θ 越高越保守（漏放少、误拒多）。数据有冗余时宁可高。

## 五、风险与不确定性

- 结构化幻觉也可能**不难挡**（如果混淆对的类在特征空间里离得远）。这是实验要回答的，不是我能预判的。
- `ConsensusValidator` 的自举设计（第一个任务无条件信任）是一个**人为选择**，换个自举方案结果会变。
- 全部实验仍是 MNIST 级规模（784 维、10 类、5 任务）。再往上（ImageNet 级、上百任务）没验证过。
- 冷备的第二条使用路径始终没做，"校正"这个词到目前为止仍然只是注释。
