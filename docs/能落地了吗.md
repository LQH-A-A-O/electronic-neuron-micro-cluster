# 现在可以落地了吗（2026-10-18）

## 一、一句话回答

> **可以做「个人 / 小团队的单机知识助手」落地，现在就能用。**
> **但不能当生产服务上线** —— 缺鉴权、限流、持久化，且知识库规模只验证到万级。

## 二、现在就能用的（全部实测）

| 能力 | 数字 | 出处 |
|---|---|---|
| 知识问答准确率 | **80.0% ±7.5%**（110 条） | 130 条基准 |
| 不可答时弃答率 | **85%** | 同上 |
| 单次延迟 P50 / P95 | **0.125 / 0.175 秒** | 6 小时压测 121,428 条 |
| 6 小时稳定性 | **0.003% 异常，显存无泄漏** | 同上 |
| 并发 | **8 并发零失败，10.9 请求/秒** | 并发测试 |
| 向量检索（改写查询） | **87%** | bge 检索验证 |
| 代码任务（3B） | **0.677** | HumanEval 164 |
| 代码任务（3B→9B 级联） | **0.738** | 同上 |

**服务已在跑**：`http://127.0.0.1:8497/`（serve_mem.py）

最新一轮 9/9 全对（含"知识问答准确率 0.800"这个曾经失败过的用例）。

## 三、能落地到什么程度

### ✅ 个人用 / 内部小工具 —— 现在就可以

- 问自己知识库里的事实，答案附召回依据
- 问到没有的东西会明确说「不知道」，不瞎编
- 响应 0.1~0.2 秒，跟本地应用一个体感
- 关掉服务不影响数据（记忆全在 `.memory/` 的 markdown 里）

### ⚠️ 小团队（2~8 人）—— 可以，但要接受排队

| 并发 | P50 | 吞吐 |
|---|---|---|
| 1 | 0.22 秒 | 4.5 请求/秒 |
| 8 | 0.70 秒 | **10.9 请求/秒** |

### ❌ 生产服务 —— 不行

| 缺口 | 现状 |
|---|---|
| 鉴权 | 没有 |
| 限流 | 没有 |
| 数据持久化 | facts 从 markdown 读，改完要重启 |
| 故障恢复 | 进程挂了要手动重启，没有守护 |
| 监控 | 只有 `/api/stats` 一个数字 |
| 知识规模 | 只验证到 1 万条；真实文档只有 70% |

## 四、三个必须知道的坑（都实测踩过）

### 1. 记忆会被污染 —— 而且会自我强化

**实测**：模型答错的 `intent_map_accuracy = 0.81` 被写进对话记忆，
之后模型读到自己的错误就照抄，`episodes.md` 里堆了 5 条。

**已修**：验证不通过时写「未验证猜测」而不是「回答」；依据记事实的 key，不记模型的答案。

**但这意味着**：如果你手动往 `facts.md` 里塞了错数据，系统会一直错下去——**记忆是权威的**。

### 2. 绝对不能拿模型的输出喂模型

| 场景 | 后果 |
|---|---|
| 用模型自采样当记忆记录 | 门控 precision = **0.000** |
| 把模型错答案当历史 | 越错越自信 |
| 用模型生成的事实建库 | 库看起来干净，其实全是它的偏见 |

### 3. 真实文档只有 70%，且主因不是检索算法

87 份真实文档 / 527 切片：纯向量 **50%**，加关键词 **70%**。
失败的 3 个全是「同一指标多个历史值」——`0.677` 出现在 **23 个切片**里。

**已缓解**：`.memory/` 的 facts 是唯一真源 + `memory_check.py` 能报冲突。
**未解决**：真实文档转 facts 的过程仍需人工。

## 五、要真落地，还差这几件事（按优先级）

| # | 事项 | 工作量 | 为什么必须 |
|---|---|---|---|
| 1 | **进程守护 + 自动重启** | 小 | 现在挂了要手动起 |
| 2 | **把真实文档转成 facts（人工整理）** | **大** | 直接决定准确率是 70% 还是 80% |
| 3 | **加鉴权 + 限流** | 中 | 不加不能暴露到局域网 |
| 4 | **记忆的清理/归档策略** | 中 | episodes 会无限增长 |
| 5 | **意图映射覆盖更多指标** | 中 | 现在 13 个指标，81% 准确 |

## 六、诚实边界

1. **80% 是在我构造的 60 条事实 + 110 条查询上测的** —— 换到你的真实知识库要重测。
2. **9/9 那个测试只有 9 个问题**，置信区间约 ±12 个百分点。
3. **"能落地"这个判断是我的评估，不是实测** —— 我没有在真实业务场景里跑过。
4. **服务现在能跑，但启动过程依赖手动确认端口空闲**，这条体验很差。
5. **所有验证都是单机、单用户、无网络暴露的**。
