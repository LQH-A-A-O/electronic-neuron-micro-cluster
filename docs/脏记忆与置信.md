# 脏记忆 + 高置信：**级联能救，但阈值必须按任务重标**（2026-10-17）

## 一、上一轮的预测（错的）

我上一轮推断："记忆任务的置信度是 −0.0002（几乎最大），所以模型对抄错的记录也会很自信，
**级联救不了这类错误，只有门控记忆能救**。"

**实测表明这个预测只对了一半。**

## 二、实测（脏记忆 raw，400 题，准确率 0.912，35 道错）

**按 mean_logprob 四分位**：

| 组 | mean_logprob 区间 | 题数 | **通过率** |
|---|---|---|---|
| 1（最低） | ≤ −0.0002 | 100 | **0.670** |
| 2 | −0.0002 ~ −0.0001 | 100 | 0.990 |
| 3 | −0.0001 ~ −0.0001 | 100 | 0.990 |
| 4（最高） | > −0.0001 | 100 | **1.000** |

> **分离是存在的**（0.670 → 1.000），但远不如代码任务（0.293 → 0.951）。
> 而且绝对值全部挤在 0 附近（−0.0002 ~ −0.0001）—— **分布比代码任务窄两个数量级**。

## 三、关键发现：**同一个绝对阈值，在两个任务上完全不同的行为**

用 HumanEval 标定的阈值 **−0.046**：

| 指标 | 数值 |
|---|---|
| 升级率 | **4.5%**（18/400） |
| 错题被抓到 | **15 / 35 = 42.9%** |
| 升级后准确率上限 | 0.912 → **0.950** |

**但阈值 −0.046 对记忆任务根本不对** —— 它的实际分布是 −0.0002 ~ −0.0001，阈值比整个分布低 200 倍。

### 换个算法：按任务自身分位取阈值

| 判据 | 升级率 | 错题覆盖 |
|---|---|---|
| 绝对阈值 −0.046（HumanEval 标定） | 4.5% | **42.9%** |
| **按本任务分位取最低 25%** | 25% | **33/35 = 94%** |

> **错题几乎全部集中在最低置信的 25% 里（33/35 = 94%）。**
> **只要按任务自身分布取阈值，级联就能抓到绝大多数抄错。**

## 四、结论（对上轮预测的修正）

| 我上轮说 | 实测 |
|---|---|
| "级联救不了抄错" | ❌ **错**。按任务分位取阈值，能覆盖 94% 的错题 |
| "只有门控记忆能救" | ✅ **对**。门控记忆直接把 0.912 提到 **1.000**（零升级率） |
| "高置信 ≠ 正确" | ✅ 对，但**高置信仍是有效信号**，只是要相对化 |

### 正确的设计规则

> **绝对阈值不可跨任务迁移。必须用"任务内相对分位"或"归一化置信度"来定阈值。**
>
> 代码任务：bottom 20% → 0.242 通过率 → 升级后 0.738 @ 10.4s
> 记忆任务：bottom 25% → 0.670 通过率 → 升级后 0.950（若 9B 全救回）

### 但记忆任务上，级联仍然不如门控记忆

| 方案 | 准确率 | 升级率 |
|---|---|---|
| 脏记忆 + 3B | 0.912 | 0% |
| **门控记忆 + 3B** | **1.000** | **0%** |
| 脏记忆 + 级联（25% 升级） | 0.950（上限） | 25% |

> **门控记忆用零额外推理延迟拿到 1.000，级联花 25% 升级才到 0.950 上限。**
> **所以在"知识对不对"这个问题上，记忆层完胜级联；级联赢在"推理难不难"上。**

## 五、诚实边界

1. **0.950 是上限**（假设 9B 把被抓到的错题全救回来），**没实测**。
2. **94% 这个覆盖率的计算**：25% 分位组 100 题、通过率 0.670 → 33 道错；总错题 35 道 → 94%。
   这是**按分位组内平均通过率推算的**，不是逐题精确统计（分组边界会有误差）。
3. **只有一个任务、一个规模（200 实体、400 题）**。
4. **mean_logprob 在极低值区间数值精度有限**（−0.0001 与 −0.0002 的差别可能受浮点/分词影响）。
5. **没有真的跑"脏记忆 + 级联"的 9B 升级**。
