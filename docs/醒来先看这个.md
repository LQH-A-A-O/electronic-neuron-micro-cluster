## 三、这套东西的真实水平（一句话）

> **它不是一个更聪明的模型，而是一个「能把外部知识准确搬出来、并明确说不知道」的小模型系统。**
>
> - 没有记忆时几乎一无所知：**3.6%**
> - 有记忆时：**80.0% ±7.5%**
> - 问到库里没有的：**85% 会说「不知道」**（无记忆时是 100% 乱编）

## 四、四个值得你注意的结论

### 1. 🚩 门控记忆会被「一致幻觉」彻底骗过

用模型自己的输出当记录流，门控 **precision = 0.000**（30 条事实，收下 15 个值全错）。
模型对「超时毫秒数」有先验偏见，5 次采样全给 300000，门控投 5/5 票通过了它。

> **记忆写入源必须是外部独立数据，不能是模型自采样。**

### 2. 基座 LLM 的隐状态不能当检索向量

Qwen2.5-1.5B 三种 pooling 的「平均领先」全是**负数**（召回 3~4/15），
换成 **bge-small-zh（26 MB）** 立刻到 **13/15 = 87%**，领先翻正。

### 3. 真实文档只有 70%，主因是「冗余 + 版本冲突」

87 份文档 / 527 切片，纯向量 **50%**，加关键词混检 **70%**。
失败的 3 个全是"同一指标多个历史值"——**同一个 0.677 出现在 23 个切片里**。

> **知识库最大的敌人不是"查不到"，是"查到了过时的那一条"。**

### 4. 双通道架构端到端约 81%

数值走结构化表（给定 key 时 100%）+ 意图映射（规则匹配 81%）。
失败模式变成"查错指标"，**这个可以靠追问解决**，而"答出过时值"不行。
