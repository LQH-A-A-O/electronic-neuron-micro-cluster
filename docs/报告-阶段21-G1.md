# 报告 · G1（阶段 21）—— 对上主动学习基线：D1 的最终审判

## 为什么这一条还能推翻 D1

阶段 20 的朴素对手是"**随机**抽样本去标注"，门控省了 84%。
但主动学习（active learning）正是干这个的：**用模型的不确定性挑最值得标的样本**。
如果一个熵采样基线在同等预算下追上门控，那 D1 不成立 —— 门控没有必要存在。

## 设计

一切沿用阶段 20：同一个流、同一个预测器（线性判别器 + kNN 回退）、同一批 seeds。
唯一变量 = **每轮花 B 次 oracle 去标哪些样本**。

- **gate**：门控。锚/peer 都明确就自己判，犹豫才花钱。
- **al_random**：随机挑 B 条（阶段 20 的对手，作为对照）
- **al_entropy**：挑**预测熵最大**的 B 条
- **al_margin**：挑 **top1−top2 间隔最小**的 B 条
- **full**：B=50/轮，全部标注（上界）

## 结果（真实 MNIST / 污染 40% / 5 seeds）

| 组 | 总体 ACC | oracle 花费 |
|---|---|---|
| **gate（门控）** | **0.706±0.033** | **97** |
| full（全标注上界） | 0.851±0.009 | 2000 |
| al_random B=5 / 10 / 20 | 0.627 / 0.663 / **0.755** | 200 / 400 / 800 |
| al_entropy B=5 / 10 / 20 | 0.617 / 0.661 / **0.738** | 200 / 400 / 800 |
| al_margin B=5 / 10 / 20 | 0.611 / 0.665 / **0.739** | 200 / 400 / 800 |

## 结论

1. **主动学习在这条赛道上没有赢，甚至略输给随机。**
   B=20 时：熵采样 0.738、间隔采样 0.739，而随机标注是 **0.755**。
   两种主动学习策略曲线几乎重合，说明它们挑的是同一批样本（都是决策边界附近的难样本）。

2. **机制解释（这是本轮最有价值的一句）**：
   **模型会把噪声学进去，于是被污染的样本反而变得"确定"。**
   熵采样的前提是"模型不确定的地方最值得问"，但在 40% 标签污染的流里，
   模型对脏样本往往是**自信的**（它已经把错标签学成了规律）—— 于是**熵采样根本挑不中污染**。

   而门控**不依赖"模型有多确定"**，它依赖**"两条证据通道是否互相印证"**。
   这是它与主动学习的根本区别 —— 也是它在这个场景里赢的原因。

3. **D1 最终判定：通过。**
   门控 97 次拿到 0.706；随机标注要 ~587 次，最好的主动学习要 **~625 次** —— **省 84%**（通过线是 30%）。
   同等花费下 ACC 高 0.111（通过线 0.05）。

## 对落地标准的更新

- **D1：✅ 通过（已对两种对手验证：随机标注、主动学习）**
- **D2：🟡 边缘**（MNIST 83% / FMNIST 86%，线是 85%）
- **D3：🟡 部分**（Fashion-MNIST 复现，但仍是 28×28 灰度图，同一种任务）
- **D4/D5/D6：❌ 未触碰**（自然坏锚 / 超参标定 / 资源账）

## 诚实边界

1. **主动学习的实现是"每轮只标 B 条、且只看当前轮"**，没有跨轮全局选样，也没有做 batch 去重。
   更强的 AL 实现（coreset、BADGE、跨轮累积）没有试。
2. 预测器仍是**双方共用**的（线性判别器 + kNN），不是各自的最佳实现。
3. AL 的不确定性来源在工具不可用时退回 kNN 投票熵，这个降级路径没有单独评估。
4. 只有 5 个种子，且仍是 MNIST。
5. **污染是"结构化标签翻转"**，不是真实标注错误。真实错误往往与内容相关，
   那会更有利于（也可能更不利于）主动学习 —— 未测。
